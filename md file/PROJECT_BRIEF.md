# PROJECT BRIEF — HECHTER

## Project
Create a professional showcase website for HECHTER, a printing company.

The website must communicate:
- Industrial expertise
- Printing quality
- Production capacity
- Reliability
- Modern equipment
- Professional customer service

## Reference Website
Reference: https://www.imprimerie-chirat.fr/

Use the reference only as inspiration for:
- Visual hierarchy
- Section rhythm
- Premium industrial feeling
- Dark/light section contrast
- Large typography
- Professional image layout
- Smooth subtle motion

Do NOT copy:
- Code
- Images
- Text
- Exact layouts
- Branding

Create an original website for HECHTER using the provided sitemap, logo and colors.

## Brand
Company name: HECHTER
Industry: Printing / Packaging / Communication
Style: Premium, industrial, corporate, modern, clean.

## Required Technology
Use only:
- HTML5
- CSS3
- Vanilla JavaScript

Do NOT use:
- Next.js
- React
- Vue
- Tailwind
- Bootstrap
- Any heavy framework

The code must be simple, clean and easy to edit.
